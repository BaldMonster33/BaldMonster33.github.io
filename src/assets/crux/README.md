# CRUX launch-page images

The four screen captures are unchanged copies of CRUX 1.4 (20)'s approved
App Store screenshots. They show actual public Release UI, captured on an
isolated iPhone 17 Pro Max simulator on September 7, 2026, with a rights-cleared
synthetic climbing sample. They are not personal session photos, owner-library
media, fresh 1.4.1 captures, or evidence of automatic video classification.

The icon is the existing CRUX app icon. Le Qin owns the app and these portfolio
assets; they are not offered under the website code's MIT license.
