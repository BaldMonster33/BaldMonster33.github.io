The original repository and course postmortem preserve the game's systems:
AR seed placement, map exploration and interaction scenes, tree growth,
inventory and shop controls, compass and landmark cues, squirrel defense with
acorn projectiles, and shared state across scenes. This was a solo game built
by two teammates, not a multiplayer game.

The playable scene above is an **illustrative browser reconstruction**, using a
generated park instead of a device camera. Its water and boost actions and five
growth stages simplify the planting idea; they do not reproduce the original
mobile mechanics. The linked recording is the team's original *Ann Arbor Go*
demo. The original deployable mobile build has not been recovered.
