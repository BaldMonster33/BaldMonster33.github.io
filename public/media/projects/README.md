# Portfolio visual sources

These assets accompany the academic case studies at https://www.qinle.ltd/projects/.
They are excluded from the website code's root MIT license. Original authors and
other rightsholders retain their existing rights; hosting an excerpt or a figure
does not grant a new license to the underlying work.

available code. New explanatory diagrams and short edits are portfolio
presentations; they do not replace the original artifacts or extend the claims
